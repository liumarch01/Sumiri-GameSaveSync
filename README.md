# Sumiri-GameSaveSync（GameSS）
### 关于项目
- 这是一个用与在安卓设备与其他安卓设备之间，或是在Windows/NAS中同步存档的APP
- 项目采用类似与git的同步方式，通过对比文件的时间戳、文件大小，哈希值等方式来实现自动上传/同步最新的存档文件

---

### 使用指南
- 共享文件夹名称中如果使用的为整个硬盘（如D:\）那么就填写D$或是D
- 如果是使用文件夹（如GameSave）那么就填写GameSave
- 在【文件管理】中的‘本地文件’列表以及‘远端存储’列表中选择需要同步的路径，如何点击右上角添加映射规则即可添加同步规则，规则会使用当前打开的目录作为同步路径。在主页中选择要同步的规则即可开启同步
- [介绍视频【在安卓设备中实现(云)存档同步】](https://www.bilibili.com/video/BV1jh486mEdg/?share_source=copy_web&vd_source=fcd9e777114827b00beaa746c11dcfde)
